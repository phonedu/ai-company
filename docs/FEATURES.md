# 功能与边界

## 核心概念

- **幕僚长（Assistant）**：唯一对话入口；负责理解需求、拆解任务、招募员工、汇总汇报。
- **员工（Employee）**：按角色执行任务（开发/评审/写作等）；有独立会话、人设、技能与模型偏好。
- **任务（Task）**：真实工作单元；按风险等级走不同闸门，状态与事件可审计。
- **工作项（Work Item）**：任务的执行片；由员工提交产出，verifier 独立验收。
- **项目（Project）**：任务与文件的边界；决定工作目录、默认模型、权限与预算。

## 已实现

| 面 | 能力 |
|---|---|
| 对话 | 老板频道、范围选择（公司/项目）、自然语言建任务、说话人区分、附件 |
| 任务 | 计划生成/编辑、critic 评审、批准、派工、暂停/恢复、打回返工、合并、归档/续办 |
| 验收 | verifier 独立会话、验收标准逐条核对、机器检查命令、计划步骤交代 |
| 员工 | 招募、人设/技能/模型配置、在职/停用、自动补评审 |
| 知识 | 笔记 CRUD、Markdown 渲染/编辑、正文搜索、媒体预览、产物多版本 |
| 成本 | 今日成本、会话用量、项目级默认预算、槽位 |
| 通道 | 微信单 owner（可选）、系统通知/托盘、待办清除 |
| 设置 | 供应商与 Key、模型目录/策略、权限档、调度、外观、数据目录 |

## 明确不做（v0.1）

- 云同步 / 账号 / 多租户 / 团队协作 / 企业 SSO；
- 移动端 App（微信通道仅消息桥）；
- 插件市场 / 在线技能商店；
- 内置模型额度或代理充值（BYO-key）。
