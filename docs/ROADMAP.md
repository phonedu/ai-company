# 路线图（Ideas）

> 以下**没有排期，也不承诺实现**；维护者按自己的使用与兴趣决定。

## 正在做

- 0.1.x：稳定性、安装/更新体验、文档。

## 可能做

- 多项目/多员工的成本与调度可视化；
- 更强的检索与项目记忆；
- 更多模型供应商适配；
- 导出/迁移（任务、笔记、账本）；
- UI 细节与无障碍。

## 不做

- 账号、云同步、多人协作、企业 SSO；
- 移动端 App；
- 插件市场/在线技能商店；
- 内置模型额度/代充。

## 已知限制

- Windows 为主要发布平台；其他平台未验证；
- 未签名安装包；
- 跨版本自动更新安装尚待下个版本实测。
