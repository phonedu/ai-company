# 数据与隐私

## 存储位置

| 内容 | 位置 |
|---|---|
| 任务/笔记/账本/设置 | Windows `%APPDATA%\ai-company\aico.sqlite` |
| 模型 Key | `~/.aico/secrets/`（不写入数据库、不上传） |
| 项目数据 | 你接入的项目目录（任务产出、`.aico/notes`、`.aico/docs`） |
| 更新缓存 | `%LOCALAPPDATA%` 下 electron-updater 缓存（可删） |

## 隐私

- **无服务端、无账号、无遥测**；应用不会把任务/笔记/Key 上传到本项目服务器（不存在）。
- 模型调用由你配置的供应商处理；请阅读对应供应商的数据政策。
- 日志默认只落本机；提交 Issue 前请移除路径、Key、真实数据。

## 备份 / 恢复

1. 退出应用；
2. 复制整个 `%APPDATA%\ai-company` 目录（含 `aico.sqlite` 与同目录的 `-wal/-shm`）；
3. 恢复：退出应用 → 用备份覆盖该目录 → 启动。

项目产出在项目目录内，按普通文件备份即可。

## 删除

- 卸载应用**不会**删除 `%APPDATA%\ai-company`（设计如此：任务/笔记属于用户资产）。
- 彻底删除：退出应用后删除该目录，以及项目里的 `.aico/`（如不再需要）。
