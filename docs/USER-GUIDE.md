# 使用指南

## 1. 首次启动

1. 选择项目文件夹（或「先逛逛」）；项目目录用于存放任务产出与 `.aico/` 数据。
2. 设置 → 供应商与模型：填入你的模型 Key（本地保存，不上传）。
3. 在老板频道直接说要做的事，例如「给这个项目补一个 README」。

## 2. 一次任务的生命周期

```
你说需求 → 任务进入规划 → 计划卡（可编辑）
  → 低风险：直接执行；中/高风险：critic 评审 → 你批准
  → 员工执行 → 提交产出 → verifier 验收
  → 通过：完成 + 汇报卡；不通过：返工/打回
```

- 决策、验收、异常都会出现在「待我处理」；「全部清除」只清卡，不等于替你做决策。
- 任务详情可看计划步骤、验收结论、产物/证据、变更与成本。

## 3. 常用操作

- **暂停/恢复**：任务详情操作条；恢复回到暂停前状态。
- **打回返工**：验证阶段必填批注，批注会进入返工 brief。
- **合并变更**：有变更集的任务在详情页审查 diff 后合并。
- **笔记**：左栏「笔记」；支持 Markdown 渲染、搜索、媒体预览。
- **设置**：8 个直达分区；权限档决定员工可执行的动作范围，默认从严。

## 4. 数据在哪

见 [DATA.md](DATA.md)。卸载不会删除任务/笔记/设置；需要彻底清理由你手动删除数据目录。
