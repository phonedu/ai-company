# FAQ

**为什么是 GPL-3.0，不是 MIT？**
希望衍生分发保持开源；同时提供商业许可，给需要闭源分发的用户另一条路。详见 `COMMERCIAL.md`。

**为什么不做账号/云同步？**
本地优先是产品边界：任务、笔记、Key 都在本机。代价是不能多设备自动同步（可手动备份数据目录）。

**Key 会被上传吗？**
不会。Key 存本机 `~/.aico/secrets`，只用于调用你配置的模型供应商。

**支持哪些模型？**
任何 OpenAI 兼容供应商（如 DeepSeek、MiMo）；在设置里配置 Base URL/模型名/Key。

**为什么安装包会提示「未知发布者」？**
当前未做代码签名；请从官方 Releases 下载并核对 SHA-256。签名会在有正式分发需求时再评估。

**自动更新怎么工作？**
安装版从 GitHub Releases 的 `latest.yml` 检查；portable 版请手动下载新版本。

**能商用吗？**
可以，但闭源商业分发需商业许可；GPL 下分发衍生作品需开源。公司内部自用不受 GPL 分发义务约束。

**会收费吗？**
当前无付费功能；未来如有 Pro/服务，会在仓库与发布说明中明确，不会把已有免费功能悄悄收回。
